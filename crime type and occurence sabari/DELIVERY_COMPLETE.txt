🚀 HOW TO START

Step 1: Install Dependencies (if not done)
```bash
pip install -r requirements.txt
```

Step 2: Verify Database
```bash
python manage.py migrate
```
✅ Already done! Tables created successfully.

Step 3: Start Server
```bash
python manage.py runserver
```

Step 4: Get Gemini API Key
→ Visit: https://aistudio.google.com/apikey
→ Sign in with Google
→ Create API key
→ Copy the key

Step 5: Configure Gemini
→ Go to: http://127.0.0.1:8000/admin-login/
→ Login: admin / admin
→ Click "Gemini AI Configuration"
→ Paste API key
→ Select "Gemini 2.0 Flash Experimental"
→ Set status to "Active"
→ Save

Step 6: Test the System
→ Login as user
→ Upload a video
→ Watch AI generate report!
