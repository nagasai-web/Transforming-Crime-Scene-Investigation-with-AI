  1. Get your Gemini API key:
     → Visit: https://aistudio.google.com/apikey
     → Sign in with Google account
     → Click "Create API Key"
     → Copy the key

  2. Configure in admin panel:
     → Go to: http://127.0.0.1:8000/admin-login/
     → Login: admin / admin
     → Click "Gemini AI Configuration"
     → Paste your API key
     → Select "Gemini 2.0 Flash"
     → Set status to "Active"
     → Click "Save Configuration"

  3. Test the integration:
     → Click "Test API Key" button
     → Should show: "✅ API Key is valid!"

  4. Upload a video:
     → Login as user
     → Click "Upload Video"
     → Select a video file
     → Click "Process Video"
     → Wait for processing
     → View AI-generated report!
