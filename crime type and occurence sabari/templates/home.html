Welcome to Crime Detection Dashboard

Our system uses image/video analysis to detect illegal items, track incidents, and provide evidence-based reporting for safer communities.

  • 🔎 Object detection for weapons and suspicious items
  • 🎥 Video upload, live streaming & enhanced result visualization
  • 🧾 Evidence management with admin verification and reporting
  • 👤 User login, admin control panel, and secure access workflows

About this Project

This application is designed for public safety and security teams. It integrates computer vision with a user-driven evidence pipeline, providing high-confidence alerts for potential crime events.

  • Secure authentication: user and admin roles with login/register workflows.
  • Detection models: YOLO-based object detection trained for weapons and threat indicators.
  • Report dashboard: review detections, evidence validation, and incident logs.
  • Modular extension-ready architecture for future enhancements.
