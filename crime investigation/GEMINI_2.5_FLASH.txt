🚀 HOW TO USE

1. Get your Gemini API key:
   → https://aistudio.google.com/apikey

2. Configure in admin panel:
   → http://127.0.0.1:8000/gemini-config/
   → Login: admin / admin
   → Enter API key
   → Model is automatically set to "Gemini 2.5 Flash"
   → Set status to "Active"
   → Save

3. Upload a video:
   → Login as user
   → Click "Upload Video"
   → Select video file
   → AI will generate report using Gemini 2.5 Flash
